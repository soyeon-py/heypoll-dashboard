python bq_fetch.py  →  python process_data.py  →  netlify deploy --prod --dir .
⚠️ GA 포인트 전환 수치는 실제보다 크게 낮게 잡힙니다
실제 관리자 데이터(OK캐쉬백·네이버페이·L포인트 등)와 비교 시 GA 집계는 실제 전환의 약 25~30% 수준으로 추정됩니다. 주요 원인은 다음과 같습니다.
  • 배치·서버 처리 전환 미수집 — 배치차감·퀴즈이벤트 등 서버사이드로 발생하는 전환은 GA 클라이언트 이벤트가 발화하지 않습니다.
  • 앱 세션 비활성 상태 전환 — 전환 완료 시점에 앱이 백그라운드이거나 네트워크 단절 시 이벤트 유실이 발생할 수 있습니다.
  • GA 추적 동의 미완료 유저 — 개인정보 동의를 거부하거나 추적 차단 환경의 유저는 GA에 기록되지 않습니다.
  • 활성 세션 조건 — GA는 해당 기간 내 앱/웹을 직접 방문한 유저의 이벤트만 수집하므로, 세션 없이 전환만 발생한 케이스는 누락됩니다.
→ GA 포인트 전환 데이터는 패턴·파트너별 비중 분석에 활용하고, 절대 금액·건수는 관리자 시스템 데이터를 기준으로 사용하세요.
